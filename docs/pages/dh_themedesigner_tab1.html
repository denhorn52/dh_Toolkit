Preferences Tab
3.01 Preferences tab:

The App Scale panel:

Displays the current App scale. Use the menubox to select a scale setting. Click the "Scale App" button to set the scale.

The Themes panel:

Displays the current theme. Use the menubox to select a theme. If "User" theme is selected it displays the current selected user theme, and a menubox to select a user theme. Use the "Set Theme" button to set the theme. (Setting a theme will replace any theme currently being edited.)

The User Themes panel:

If a user theme is selected the "User Theme Name" textbox displays the name to be used when saving the currently edited theme.

Type in or edit the name as you see fit.

(Hint: Right-clicking the "Current User Theme" menubox copies the name in the "Current User Theme" menubox to the "User Theme Name" textbox.)

Use the "Rename" button to rename the current user theme with the name in the "User Theme Name" textbox.

Use the "Delete" button to delete a user theme.

Use the "Save Theme" button to save the current theme using the name in the "User Theme Name" textbox.

"Save to console" checkbox. If checked will also print user theme to script console when saving.
