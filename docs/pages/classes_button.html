dh_Button
5.01 dh_Button:
Same as Lokasenna Button but with some renamed properties and default colors.
The Button property "func" is where you specify the name of a function which is to be called when clicking the button. 
----------------------------------------------------------------------------
   [color_name] brackets indicate that the color is hardcoded.                      
----------------------------------------------------------------------------
Class:           |    Lokasenna Button       |       dh_Button      
attribute:       | property_name   default   | property_name   default
----------------------------------------------------------------------------
text:              caption         ""          text            ""
font:              font            3 (sans16)  font            sans22
function:          func       function()end    func       function()end
parameters:        params          {...}       params          {...}

-- colors --
face:              col_fill        elm_frame   col_bg          btn_face    
outline:           [elm_outline]               col_outline     btn_outline
text:              col_txt         txt         col_text        btn_txt              
----------------------------------------------------------------------------
