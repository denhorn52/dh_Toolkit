dh_Panel
5.08 dh_Panel:
A panel with optional border and optional rounded corners.
Draws a rectangle using the color specified in "col_bg".
If "border_width is greater than 0 (default = 2) it will draw a border.
Can display text with adjustable line-height. Line height can be defined using a number multiplier. If using "use_pixels" it overrides "line_height" and uses the pixel designation as the line height. No scrolling or word wrap. If need scrolling use dh_Listbox.
(As of 7-12-2025 text only accepts a table of string values.)
