Note: Options can be specified as a table of strings using 
  opts or optarray, or a comma separated string using opts.
  Options are ultimately stored in optarray.
  If optarray or opts is not specified, or if optarray is 
  specified as an empty table (optarray = { } or opts = { }) 
  then optarray will be initialized to {"Option1"}. 
  If specified as a comma separated string (opts = "Option1, 
  Option2, Option3") it will be converted to a table and get 
  stored in optarray.
