Colors Tab
3.04 Colors Tab:

Displays the theme colors. Clicking on a color swatch updates the Toolbar section. See section "3.06 Colors Default Uses" for more details of default color uses.

The "Lokasenna defined" column shows the original Lokasenna defined GUI colors.

The "dh_Toolkit defined" columns show the additional colors defined by dh_Toolkit. The Lokasenna colors work fine for a monochrome theme, but I find that it lacks the necessary range when using colored themes. Many of these colors are meant to be used for a specific purpose, e.g., "Track fill" for slider track fill. They can, however, be used elsewhere. Some colors, such as "Button face", are used by multiple classes.

"Button face", "Button outline", and "Button text" were originally intended to style the button colors. They are also to color attributes of other classes such as button face, knob face, and slider thumb.

"Element active" is used for outlining focused elements. As of 07-22-2025 this only applies to dh_Menubox, dh_Textbox, and dh_TextEditor. It requires a high contrast with the background color. The default "elm_fill" is insufficient in many cases.

"Element text" is used for the text elements: dh_Listbox, dh_Menubox, dh_Textbox, and dh_TextEditor. It is necessary because the the Lokasenna defined text color won't show well in many themes.

"Element thumb" and "Element track" are used to color the scrollbar colors of dh_Listbox and dh_TextEditor.

"Panel background", "Panel border", and "Panel text" can be used for panels and option boxes to add an extra level of interest to the GUI.

"Selected text" is used to highlight the selected text of dh_Listbox, dh_Textbox, and dh_TextEditor. This is the only color in which the alpha value can be adjusted by using the "sel_alpha" slider on tab3. For a more detailed explanation see  3.08 Selected Text Highlights.

"Tab_active" and "Tab_inactive" is used to style the tab colors of the Tab element.

"Track_fill" is used to style the track fill color of the Slider element.

Most of the dh_Toolkit defined colors have been assigned as the default colors of the dh_Toolkit elements. Therefore each color needs to be painted with a theme compatible color. It is possible that the same color values are used by multiple theme colors. For instance, it is possible that "Text", "Button text", and "Panel text" are all the same. Another case is slider track fill. Lokasenna slider uses "Element fill" as the default, and dh_Toolkit slider uses "Track fill" as the default. If "Element fill" works for the dh_Toolkit slider simply paint "Track fill" the same as "Element fill". The following chart shows the Lokasenna colors that are comparable to the dh_Toolkit colors. A good place to start a theme would be to paint the dh_Toolkit color with the Lokasenna default and proceed from there.
