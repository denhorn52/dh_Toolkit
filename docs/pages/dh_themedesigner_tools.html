Tools Panel
3.05 Tools Panel:

"Color Names" menubox: Select a theme color. You can also select a color from a swatch on the "Colors" tab.
"Color Uses" listbox: Displays the various default uses of the selected color name.
Color sliders: Adjust these to update "New Color". Click on the Slider caption to decrement the value by one. Click on the value display to increment the value by one.
"Start Color": Displays the theme color when first selected. Clicking on the "Start Color" box updates all of the GUI elements that use the current theme color with "Start Color".
"New Color": Displays the current theme color with its edits. Clicking on the "New Color" box updates all of the GUI elements that use the current theme color with "New Color".
Reset Buttons:
If not satified with the edited "New Color" color it can be restored from the "Start Color" by clicking on the "Reset" button. When clicking two additional buttons appear. Click "Y" to confirm. Click "N" to abort. This copies the "Start Color" to "New Color".
If you are satisfied with the edited "New Color" it can be copied to (overwrite) "Start Color" by clicking the "Save" button. When clicking two additional buttons appear. Click "Y" to confirm. Click "N" to abort. "Start Color" now has the edited color. The original start color is no longer available.
Last Selected Indicators: The color boxes to the upper corners of "Start Color" and "New Color" when highlighted (white) shows which color is currently selected and being used in the GUI.
Hold Color: The "Hold Color" swatch is located just above the "Reset" button. This is used to transfer colors. Clicking on the swatch copies either the "Start Color" or "New Color" into it, whichever was last selected. It can also be populated by right-clicking on a color swatch on the "Colors" tab. It will hold that color until it is repopulated by one of the above methods. Now if you select another theme color from the "Colors" tab or the "Color Names" menubox the "New Color" box gets the newly selected theme color, but the "Hold Color" is still there. Clicking on the arrow button to the right of the "Hold Color" swatch will copy the hold color into the "New Color".
