Installation
1.01 Installation:
Install the Lokasenna GUI:
Install Lokasenna_GUI if not already done. This can be installed automatically by using the Reapack add-on for Reaper. On my computer this resulted in the following file structure:
E:\Reaper6\Scripts\ReaTeam Scripts\Development\Lokasenna_GUI v2
The files can also be installed manually:
1. Navigate to the Lokasenna site.
2. Download the files by clicking on the "Code" button and then clicking on the "Download ZIP" option in the popup window. Save it to your local device.
3. Open the ZIP file.
4. Inside the ZIP file there is a directory "Lokasenna_GUI v2". If you are planning to do any developing you should extract this directory somewhere in the "Reaper/Scripts" directory. If you are not planning on doing any developing you only require the subdirectory "Library". The "Library" directory contains all the files needed to run the scripts. You can extract the "Library" directory and its contents to somewhere in the "Reaper/Scripts" directory. (Even if not planning to do any development it is okay to include the entire "Lokasenna_GUI v2" directory.)
5. The "Library" directory contains the file "Set Lokasenna_GUI v2 library path.lua". You must run this script to add the Lokasenna library path to the "reaper-extstate.ini" file. User scripts look there when loading files when running a user script.
5.01 In Reaper's main menu click "Actions" then "Show action list". This opens the "Actions" window.
5.02 Click the "New action" button then click "Load Reascript" from the dropdown menu.
5.03 Browse to the Lokasenna "Library" directory and select the "Set Lokasenna_GUI v2 library path.lua" file. Click open.
5.04 This file now appears in the action list as: "Script:Set Lokasenna_GUI v2 library path.lua". Select it.
5.05. Click the "Run" button. The path should now be set.

Install dh_Toolkit:
Install dh_Toolkit. As of 06-22-2025 this can only be done manually.
1. Navigate to the dh_Toolkit site.
2. Download the files by clicking on the "Code" button and then clicking on the "Download ZIP" option in the popup window. Save it to your local device.
3. Open the ZIP file.
4. Extract the directory "dh_Toolkit_v1" and its contents to Reaper/Scripts/ directory.
5. The "library" subdirectory contains the file "Set dh_Toolkit_v1 library path.lua". You must run this script to add the dh_Toolkit library path to the "reaper-extstate.ini" file. User scripts look there when loading files when running a user script.
5.01 In Reaper's main menu click "Actions" then "Show action list". This opens the "Actions" window.
5.02 Click the "New action" button then click "Load Reascript" from the dropdown menu.
5.03 Browse to the dh_Toolkit_v1 "library" directory and select the "Set dh_Toolkit_v1 library path.lua" file. Click open.
5.04 This file now appears in the action list as: "Script:Set dh_Toolkit_v1 library path.lua". Select it.
5.05. Click the "Run" button. The path should now be set.
