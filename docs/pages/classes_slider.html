dh_Slider
5.09 dh_Slider:
Provides either a horizontal or vertical slider with optional caption. Caption and entire slider element use the same background and text colors. Same as Lokasenna Slider with the following modifications and enhancements:
Changed some property names.
Added thickness "thk" property. This affects the track thickness and the size of the track thumb(s). 
----------------------------------------------------------------------------
   [color_name] brackets indicate that the color is hardcoded.                      
----------------------------------------------------------------------------
Class:           |    Lokasenna Slider       |       dh_Slider      
attribute:       | property_name   default   | property_name   default
----------------------------------------------------------------------------
caption:           caption         nil         caption         nil
caption font:      font_a          3 (sans16)  font_caption    sans20
values font:       font_b          4 (sans16)  font_text       sans16
track thickness:   [8]                         thk             8
direction:         dir             h           dir             h

-- colors --
background:        bg              wnd_bg      col_bg          wnd_bg 
text:              col_txt         txt         col_text        txt
track bg:          [elm_bg]                    col_track       elm_bg
track outline:     [elm_outline]               col_outline     btn_outline
thumb face:        col_hnd         elm_frame   col_thumb       btn_face
thumb outline:     [elm_outline]               col_outline     btn_outline
track_fill:        col_fill        elm_fill    col_fill        track_fill
----------------------------------------------------------------------------
