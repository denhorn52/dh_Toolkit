dh_Textbox
5.11 dh_Textbox:
Same as Lokasenna Textbox except changed most of the property names for consistency with other dh_Toolkit classes.
Allows all of the color properties to be overridden.
Note: Caption is optional. If used it will use "col_cap_bg" and "col_cap_text" colors. 
----------------------------------------------------------------------------
   [color_name] brackets indicate that the color is hardcoded.                      
----------------------------------------------------------------------------
Class:           |    Lokasenna Textbox      |       dh_Textbox      
attribute:       | property_name   default   | property_name   default
----------------------------------------------------------------------------
text:              retval          ""          retval          ""
caption font:      font_a          3 (sans16)  font_caption    sans20
text font:         font_b          monospace   font_text       mono16
padding top left:  pad             4           pad             4

-- colors --
caption bg:        bg              wnd_bg      col_cap_bg      wnd_bg         
caption text:      color           txt         col_cap_text    txt
box bg:            [elm_bg]                    col_bg          elm_bg
box frame:         [elm_frame]                 col_frame       elm_frame
box text:          color           txt         col_text        elm_txt
selected text:     [elm_fill]                  col_sel_text    sel_txt
outline focused:   [elm_fill]                  col_active      elm_active
----------------------------------------------------------------------------
