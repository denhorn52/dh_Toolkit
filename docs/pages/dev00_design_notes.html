6.00 Design Notes:

When developing a script keep in mind the color theme. Although dh_Toolkit provides for overriding the default colors for almost every color property of its classes, it is probably best to stay with the default colors as much as possible and utilize additional colors just enough to add interest. In fact, the dh_Toolkit scripts "dh_ArrangeViews" and "dh_Snapshots" were developed before I developed "dh_ThemeDesigner" and use a very basic color theme. dh_Toolkit provides several themes to test your script with. See section 3.04 Colors Tab for suggestions.
