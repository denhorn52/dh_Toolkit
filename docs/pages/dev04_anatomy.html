Anatomy of a script
6.04 Anatomy of a script:

This page illustrates the basic outline of a script utilizing the Lokasenna GUI and dh_Toolkit. The order of the steps are important to maintain. For a detailed description refer to dh_Template.lua. That is a highly commented bare-bones script that can also be considered as a tutorial.

Load required files (Lokasenna GUI; dh_Toolkit)
Define variables and data structures.
Define functions (including those used by GUI elements).
(Load any saved settings required to define GUI.)
Define GUI elements.
Override element events (e.g., mouseup)
Initialization:
Load any saved settings used by script.
Do any setup for GUI.
On exit: (See Note 1)
Provide for saving GUI settings and/or script settings.
userFunction( ) -- runs on each update loop. (See Note 2)
GUI.Init( )
GUI.func = userFunction
Tell the GUI library to run user function on each update loop.
GUI.Main( )

Note 1:
Create a function to hold your exit code and assign it to reaper.atexit (the name doesn't matter but "Exit" says it all): 

local function Exit()
    -- Your exit code --
end

reaper.atexit(Exit)

Alternatively you can use the following, as long as it appears before GUI.Init( ). 

local function Exit()
    -- Your exit code --
end

GUI.exit = Exit

Basically, GUI.Init( ) assigns it by calling 

if GUI.exit then reaper.atexit(GUI.exit) end

I prefer the first, more direct method.

Note 2:
User function to be run on every update loop. Anything that would go into a reaper.defer function would go here. You can name it whatever you wish (dh_Toolkit scripts call it "dhMain").
