Theme Designer
3.00 dh_ThemeDesigner:

This script provides a GUI to design user themes for scripts using dh_Toolkit. The script window (herein referred to as App) consists of two main parts. The top is a Tabbed section, and the bottom is the Tools section.

 3.01 Preferences Tab
 3.02 Lokasenna Tab
 3.03 dh_Toolkit Tab
 3.04 Colors Tab
 3.05 Tools  Panel
 3.06 Colors Default Uses
 3.07 Conventions
 3.08 Selected Text Highlights

Note: I pushed the limits with this. The script used 135 elements although there apparently are only 127 buffers available for elements to use. Plus some elements require more than one buffer. I believe this is why the script occasionally crashed . I combined 19 color labels on Tab4 into 3 dh_Panels which I had hoped would fix this. Seems that the script still occasionally crashes due to buffer issues. However, your work is saved. Just restart the script and it pick ups where you left off.
