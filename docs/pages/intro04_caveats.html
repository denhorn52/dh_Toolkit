Caveats
1.04 Caveats:

dh_Toolkit and its accompanying scripts were developed using a Windows 10 system, and Reaper v 6.71. I have not, and do not plan to test it on any other operating system. Therefore it may display differently on other systems.

Apparently Macs display font sizes differently than Windows does. The Lokasenna GUI attempts to compensate for this by applying a multiplier to the font sizes when run on a Mac. I don't know how effective that is.

Clicking on Menubar or Menubox calls gfx.showmenu which displays a popup menu. The font and font-size used in the popup menus are determined by the operating system and cannot be changed by the script.
