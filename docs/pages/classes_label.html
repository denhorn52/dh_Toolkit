dh_Label
dh_Label:

Same as Lokasenna Label except for changed some property names and added property 'text_pos'.

text_pos:
left: The text is placed to the left of 'x'.
center: The text is centered at 'x'.
right: The text is placed to the right of 'x'.

Note: init and draw functions added then subtracted 2 pixels from gfx.x and gfx.h. This caused labels to be displayed at design x minus 2 causing problems with tight layout. Changed to eliminate add/subtract. Doesn't seem to be causing any problems. 

------------------------------------------------------
attribute:          property_name       default value
------------------------------------------------------
text:               text               "Label"
font:               font               "sans22"
text position:      text_pos           "left"
text shadow:        shadow_text         false

-- colors --
background:         col_bg             "wnd_bg" 
text:               col_text           "txt"
