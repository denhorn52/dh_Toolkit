6.03 dh_Label:
Same as Lokasenna Label except for changed property names.
Added property 'text_pos' which can be "left", "center", or "right". This allows additional control when placing the label.
Note: init and draw functions added then subtracted 2 pixels from gfx.x and gfx.h. This caused labels to be displayed at design x minus 2 causing problems with tight layout. Changed to eliminate add/subtract. Doesn't seem to be causing any problems.
