5.10 dh_Tabs:
Same as Lokasenna Tabs except changed most property names.
When defining a Tabs element you use the "opts" property to specify either a comma separated string of tab names, or a table of strings as tab names. During element creation "opts" gets parsed into the element's "optarray" property which hold the values that are displayed. After element creation "opts" is no longer used. "optarray" now holds the list of tab names.
