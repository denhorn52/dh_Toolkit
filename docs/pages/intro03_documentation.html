Documentation
1.03 Documentation:
The "docs" directory contains all of the documentation in HTML format. If you want a local copy of this documentation then copy the "docs" directory somewhere on your device. You can place it in the dh_Toolkit_v1" directory, or anywhere you desire for easy access.
Clicking on the logo at the left of the page heading navigates to the main "Table of Contents. Clicking on the Github logo at the right of the Table of Contents navigates to the dh_Toolkit" repository on Github.
Some sections such as the "dh_ThemeDesigner" and "Classes" section has its own local table of contents. Pages under those sections have a back arrow at the right of the page header. Clicking on that will return you to the parent page.
