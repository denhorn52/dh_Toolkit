dh_Knob
6.02 dh_Knob:
Draws a knob with optional caption.
Built upon the Lokasenna Knob. Changed some property names, and added features.
Property 'centered':
    if 'centered' is false then x and y are the top-left of knob body.
    if 'centered' is true then x and y are to center of knob.
Knobs can have one of several styles:
Pointer: Displays a knob with a triangular pointer attached to the knob body.
Flange: Displays a knob with a flange and a central body. The indicator is a white line on a black flange.
Simple: Displays a round knob with the indicator on top.
There are several ways to display the current value of the knob. You can use any or a combination of the various ways.
Values: Values are displayed as numbers around the knob.
When increasing font_values size one needs to also increase values padding, or else values may overlap.
The property 'output' can modify how or which values are displayed. I haven't attempted to use this feature. See Lokasenna docs for details.
Tickmarks: Use tickmarks instead of number values.
The tickmarks are those tiny lines along the track that are usually set to the number of track steps or a fraction thereof. You can set the size of the tickmarks. Hard ticks refers to a set of tickmarks which can be enhanced with length and/or thickness. Hard ticks are specified as a table, e.g., {0, 5, 10} which indicate at which positions the hard ticks will be displayed.
Min-max values: Displays alpha-numerical values at specified steps. Although the property is called 'min_max_values' it can also display additional values. They are specified in a table, e.g., {{0,"0"}, {5,"5"}, {10,"10"}}. Each item contains the position (step) and the value to be displayed. The value is a string so anything alpha-numerical is valid.
Note: The properties 'max', 'hard_ticks', and 'min_max_values' have a relationship between them. When changing 'max' be sure to adjust the latter two as necessary.
Indicator: Indicator color depends on the knob style. For 'pointer' style and 'simple' style it is automatically derived from the body color (default "btn_txt"). 'flange' style uses "white"'.
Display: The current value can be displayed in a box above (or below) the knob. If 'display_style' is "box" the box is similar to a textbox using 'display_bg' color. If 'display_style' is "plain"' the values are displayed in the area defined by the display box, but with no outline and using the background color of where the knob is placed. 'display_pad_x' and 'display_pad_y' are used to tweak the position of the box. 'display_align' is used to position the value text inside the box. It can be "left", "center", or "right".
Frame color, by default, uses highlight/lowlight colors that are automatically calculated from the 'col_backdrop' color. However, the frame can be set to use a single color (specified by the 'col_frame' property) by setting 'frame_use_outline' property to true. Some themes can call for single color outlines regardless of the 'frame_use_outline' setting.
