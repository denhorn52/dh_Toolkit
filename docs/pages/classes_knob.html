dh_Knob
5.02 dh_Knob:
Draws a knob with optional caption. Caption and entire knob element use the same background and text colors.
Same as Lokasenna Knob except changed some property names.
Added property "centered".
    if centered is false then x and y are to edges of knob.
    if centered is true then x and y are to center of knob.
When increasing font_text size one needs to also increase knob w and h, or else text overlaps. 
----------------------------------------------------------------------------
   [color_name] brackets indicate that the color is hardcoded.                      
----------------------------------------------------------------------------
Class:           |    Lokasenna Knob         |       dh_Knob      
attribute:       | property_name   default   | property_name   default
----------------------------------------------------------------------------
caption:           caption         nil         caption         nil
caption font:      font_a          3 (sans16)  font_caption    sans20
values font:       font_b          4 (sans16)  font_text       sans16
centered:          n/a             n/a         centered        true
       
-- colors --
background:        bg              wnd_bg      col_bg          wnd_bg 
text:              col_txt         txt         col_text        txt
knob outline:      [elm_outline]               col_outline     btn_outline
knob body:         col_body        elm_frame   col_body        btn_face 
knob pointer:      col_head        elm_fill    col_head *      txt

* color_head is also highlighted text color.
